# ⚡ Mobile Calculator - Cognifzy Internship Task 2 (JavaScript)

This project is part of my **Cognfizy Web Development Internship - Task 2**.  
It is a fully functional **mobile-style calculator** built using HTML, CSS, and JavaScript.

---

## 📱 Project Overview

This calculator is designed to look and behave like a real mobile calculator app.  
It supports basic arithmetic operations with a clean, modern UI.

---

## ✨ Features

- 📱 Mobile-like calculator UI
- ➕ Addition, ➖ Subtraction, ✖ Multiplication, ➗ Division
- 🧹 Clear (AC) button
- ⌫ Delete last input
- ⚡ Instant calculation using JavaScript
- 🎨 Modern dark UI design
- 📲 Fully responsive (mobile + desktop)
- 🎯 Button click animations

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (DOM Manipulation)

---

## 📌 Learning Outcomes

- DOM manipulation in JavaScript
- Event handling (onclick functions)
- Working with expressions and eval()
- Responsive UI design
- Real-world mini project development
